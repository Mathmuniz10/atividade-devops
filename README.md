# atividade-devops

## Descrição
Durante a atividade, um integrante realizou alterações no código enquanto o outro fez a revisão utilizando um checklist de qualidade previamente definido.

## Objetivo
Praticar o fluxo de trabalho utilizado em equipes de desenvolvimento, incluindo:
- Criação de repositório
- Uso de branches
- Commits
- Pull Request
- Code Review
- Merge
